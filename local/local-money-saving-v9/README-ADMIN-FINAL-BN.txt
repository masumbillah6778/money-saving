Admin Panel — 4 Actions Final

ইউজারের তালিকায় ঠিক ৪টি কাজ:
১. 📊 বিস্তারিত — ক্লিক করলে নির্বাচিত User-এর বিস্তারিত খুলবে।
২. ✏️ Edit — User-এর তথ্য Edit করবে।
৩. 🔒 Block / 🔓 Unblock — User-এর Status পরিবর্তন করবে।
৪. 🗑️ Delete — নিশ্চিতকরণের পর User ও তার Deposit ডাটা Delete করবে।

বিস্তারিত Card ডিফল্টভাবে বন্ধ থাকবে।
Print Sidebar-এ নেই; বিস্তারিত Card-এর ডান পাশে Print আছে।
Print করলে শুধু নির্বাচিত User-এর বিস্তারিত টেবিল প্রিন্ট হবে।
প্রথম পেজে নাম ও Member ID বড়/Bold থাকবে; পরের পেজে তা পুনরায় থাকবে না।
প্রতিটি পেজে টেবিল Header পুনরায় থাকবে।
